내 쇼핑몰에 어떤 도매처 상품이 몇 개 올라가 있는지 확인하고,
유플랫에서 상품 수를 수집해 현황판에 반영하는 방법입니다.

2026.10.23 수정본 기준 · 북마크 방식 · 최대 3개 조합 동시 조회

처음 시작항목 등록유플랫 수집결과 반영일상 관리백업·초기화문제 해결

01. 처음 시작하기

  1. 프로그램 폴더에서 사용할 HTML 파일을 더블클릭해 브라우저로 엽니다.
  2. 프로그램 파일은 쇼핑몰도매처관리.html입니다. 예시 항목만 포함된 배포용이며 같은 파일을 계속 사용하세요.
  3. 프로그램을 수정한 뒤에는 열려 있는 화면에서 F5를 눌러 새로고침합니다.

위쪽 열은 쇼핑몰, 왼쪽 행은 도매처입니다. 두 항목이 만나는 칸을 ‘셀’이라고 합니다. 예시스토어 열과 예시도매처A 행이 만나는 셀에는 해당 조합의 상태와 상품 수가 들어갑니다.

  1. 자동 등록 또는 수동 등록
  2. 북마크 저장
  3. 유플랫에서 수집
  4. 결과 파일 가져오기

02. 쇼핑몰과 도매처 등록하기

신규 마켓·도매처도 자동 등록됩니다.
유플랫에서 전체 수집 후 결과 파일을 가져오면 유효한 수량이 있는 신규 마켓·도매처가 자동 추가됩니다. 수동 등록도 가능합니다. 도매처명이 없으면 코드가 이름으로 표시되며 나중에 수정할 수 있습니다.

도매처 추가

  1. 상단의 도매처 추가를 누릅니다.
  2. 도매처 이름과 공급사 코드를 입력하고 추가를 누릅니다.
  3. 코드는 유플랫 등록제품관리의 도매처 선택 목록에 표시되는 코드와 맞추세요. 상품구분코드는 별도로 입력하지 않습니다.

쇼핑몰 추가

  1. 쇼핑몰 추가를 누릅니다.
  2. 묶음에는 스마트스토어·쿠팡 같은 마켓 종류를, 쇼핑몰명에는 내 계정의 매장 이름을 입력합니다.
  3. 유플랫 마켓 목록의 개별 쇼핑몰 이름과 일치하게 입력하고 추가를 누릅니다.
이번 자동 등록 기능을 사용하려면 기존 북마크를 새로 교체하세요. 새 버전은 실행할 때 유플랫 목록을 읽습니다. 이후 신규 항목 때문에 매번 교체할 필요는 없지만 프로그램 수집 코드가 바뀌면 교체해야 합니다.

03. 유플랫에서 상품 수 수집하기

① 현황판에서 북마크 준비

  1. 현황판 상단의 유플랫 연동을 누릅니다.
  2. 크롬 북마크바가 안 보이면 Ctrl + Shift + B를 누릅니다.
  3. 북마크바로 드래그를 마우스로 누른 채 브라우저의 북마크바로 끌어 놓습니다.
브라우저 상단: 주소창 아래에 북마크바가 표시됩니다
북마크바로 드래그→ 끌어 놓기 →북마크바 빈 자리

드래그 동작을 설명하는 그림입니다. 이 그림 자체는 실행 링크가 아닙니다.

코드를 주소창이나 개발자 도구에 붙여넣을 필요가 없습니다. 기존 수집 북마크가 있다면 삭제하고 새 링크로 교체하세요.

② 유플랫 화면에서 실행

  1. 평소 사용하는 유플랫 사이트에 로그인합니다.
  2. 등록제품관리 화면으로 이동합니다.
  3. 날짜·검색어·품절 여부 등 불필요한 검색 조건을 해제합니다. 수집에는 현재 검색 폼의 조건이 함께 사용됩니다.
  4. 북마크바에 저장한 수집 북마크를 클릭합니다.
  5. 나오는 확인창에서 원하는 수집 범위를 선택합니다.
버튼수집 범위
확인유플랫 목록의 개별 쇼핑몰 × 도매처 코드 조합을 수집합니다. 전체 계정 등 묶음 선택지는 제외합니다.
취소현재 유플랫 화면에서 선택한 마켓·도매처 한 조합을 수집합니다. 프로그램 실행을 취소하는 뜻이 아닙니다.
처음에는 한 조합으로 시험하세요.
유플랫에서 개별 마켓과 도매처를 선택하고 검색 결과가 바뀐 것을 확인한 뒤 북마크를 실행합니다. 확인창에서 ‘취소’를 눌러 한 조합을 수집하고, 화면의 수량과 비교하세요.

③ 어떤 숫자를 가져오나요?

전체: 906건 (533개 상품) (1 / 10 Page)
가져올 상품 수 = 533

괄호 안의 ‘개 상품’ 앞 숫자가 기준입니다. ‘전체 906건’이나 페이지 수는 입력하지 않습니다. 검색 결과가 ‘전체: 0건’이면 0으로 처리합니다.

④ 수집이 끝날 때까지 기다리기

현재 버전은 최대 3개 조합을 동시에 조회합니다. 실제 소요 시간은 조합 수와 유플랫 응답 속도에 따라 달라집니다. 수집 중에는 유플랫 탭을 닫거나 새로고침하지 말고, 검색 조건을 바꾸거나 북마크를 반복 클릭하지 마세요.

완료하면 유플랫_상품수_날짜와시간.json 형식의 결과 파일이 다운로드됩니다. 브라우저 다운로드 목록은 Ctrl + J로 확인할 수 있습니다.

응답을 읽지 못한 항목은 실패로 남기고, 연속 실패 시 중간에 멈춥니다. 최신 동시 조회 코드는 모의 검증을 거쳤으며 실제 유플랫에서의 속도는 별도 측정하지 않았습니다.

04. 수집 결과를 현황판에 반영하기

  1. 현황판으로 돌아와 유플랫 연동을 엽니다.
  2. 수집 결과 파일 가져오기를 누릅니다.
  3. 방금 다운로드한 유플랫_상품수_…json 파일을 선택합니다.
  4. 파일을 선택하면 자동으로 반영됩니다. 아래의 ‘반영 완료’와 업데이트·건너뜀 개수를 확인합니다.
  5. 닫기를 누르고 표의 상품 수를 확인합니다.

가져온 파일은 선택 즉시 반영됩니다. 별도의 결과 반영 버튼이나 붙여넣기 칸은 없습니다. 확인이 끝나면 파일 가져오기 옆의 닫기를 누르세요.

상단 ‘불러오기’와 헷갈리지 마세요.
유플랫 수집 파일은 유플랫 연동 → 수집 결과 파일 가져오기에서 넣습니다. 상단 ‘불러오기’는 현황판 전체 백업을 복원하는 기능입니다.
  • 수집된 상품 수와 날짜가 해당 셀에 반영됩니다.
  • 직접 지정한 예정·일부·문제 상태는 유지됩니다. 그 외 상태는 수량이 1개 이상이면 완료, 0개이면 미진행으로 바뀝니다.
  • 수집에 성공한 신규 항목은 자동 추가합니다. 실패 항목은 건너뛰며 실패 수량을 0으로 덮어쓰지 않습니다. 삭제했던 항목도 유플랫에 있으면 다시 추가됩니다.
  • ‘마지막 업로드일’ 칸에는 수집 결과의 날짜가 반영됩니다. 실제 상품 업로드 날짜를 조회해서 가져오는 것은 아닙니다.

05. 평소에 현황판 관리하기

하고 싶은 일사용 방법
상태 바꾸기셀을 한 번 클릭합니다. 미진행 → 예정 → 일부 → 완료 → 문제 순서로 바뀝니다.
수량·메모 수정셀을 더블클릭해 상품 수, 날짜, 메모 등을 입력한 뒤 저장합니다.
이름·코드 수정도매처명 또는 쇼핑몰명을 클릭해 수정합니다. 변경 후 수집 북마크도 교체합니다.
여러 항목 삭제도매처 삭제 또는 쇼핑몰 삭제를 누르고 여러 항목을 선택한 뒤 아래 삭제 버튼을 누릅니다. 해당 항목의 셀 기록도 함께 삭제됩니다.
순서 바꾸기도매처 순서 또는 쇼핑몰 순서에서 항목을 선택하고 맨 위·위로·아래로·맨 아래를 누릅니다. 행 또는 열의 위치가 바뀝니다.
원하는 항목 찾기검색창에 이름·코드를 입력하거나 묶음·상태 필터를 사용합니다. 전체를 다시 보려면 필터 해제를 누릅니다.
표가 화면보다 클 때하단 가로 스크롤바로 좌우 이동합니다. 아래로 스크롤해도 상단의 쇼핑몰 머리글로 열을 확인할 수 있습니다.

06. 백업, 복원, 초기화

작업이 끝나면 ‘저장하기’

수정 내용은 브라우저에 저장되지만, 브라우저 데이터 삭제나 다른 컴퓨터 사용에 대비해 저장하기로 백업 JSON을 내려받으세요. 브라우저 저장은 별도의 백업 파일과 다릅니다.

불러오기에서 이 백업 JSON을 선택하면 현재 현황판 전체 내용이 백업 내용으로 교체됩니다. 기존 화면을 남기려면 먼저 저장하기로 백업하세요.

다른 사람이나 컴퓨터로 보내기

프로그램 HTML을 전달합니다. 관리 데이터까지 옮길 때는 저장하기로 만든 백업 JSON도 함께 전달하고, 받는 쪽에서 프로그램을 연 뒤 불러오기로 복원합니다. 전달할 백업에는 본인의 관리 데이터가 포함되므로 공유 범위를 확인하세요.

초기화하면 이렇게 됩니다

  • 도매처: 예시도매처A, 예시도매처B 두 개만 남습니다.
  • 쇼핑몰: 스마트스토어 묶음의 예시스토어 하나만 남습니다.
  • 체크 상태와 메모 등 기존 셀 기록이 삭제됩니다.
초기화는 새로고침이 아닙니다. 화면만 다시 보려면 F5를 누르세요. 초기화 전에는 반드시 백업을 저장하세요.

CSV 내보내기는 표 내용을 다른 도구에서 확인할 때 사용할 수 있습니다. 현황판 전체 보관·복원용으로는 저장하기의 JSON 백업을 사용하세요.

07. 자주 막히는 부분

추가한 신규 쇼핑몰·도매처가 수집되지 않아요.

자동 등록 기능이 포함된 새 북마크인지 확인하세요. 결과 파일을 가져와야 등록됩니다. 해당 조합의 수집 실패 또는 인식되지 않는 목록 형식은 자동 등록되지 않습니다.

북마크바로 드래그를 눌렀는데 실행되지 않아요.

현황판의 링크는 북마크바로 끌어 놓아 저장하는 용도입니다. 저장한 북마크는 유플랫 등록제품관리 페이지에서 클릭해야 합니다.

콘솔 경고나 구글 검색 오류가 떠요.

현재 방식은 주소창·콘솔 붙여넣기가 필요 없습니다. 유플랫 등록제품관리 화면으로 돌아가 새로 등록한 북마크를 사용하세요.

일부가 건너뛰어지거나 중간에 멈췄어요.

유플랫 로그인 상태를 확인하고, 날짜·검색어 등 검색 조건과 현황판 이름·코드를 점검하세요. 다시 로그인했다면 등록제품관리로 이동해 한 조합부터 시험하세요. 건너뛴 항목은 완료된 것으로 보지 말고 개별 확인하세요.

개수가 예상보다 작거나 이상해요.

유플랫에서 같은 마켓·도매처를 직접 선택해 검색하고 괄호 안 상품 수와 비교하세요. 남아 있는 검색 조건, 비슷한 쇼핑몰 이름, 잘못 등록된 도매처 코드를 확인하세요.

속도 개선판인데 여전히 느려요.

기존 북마크에는 예전 코드가 들어 있을 수 있습니다. 현황판을 F5로 새로고침하고 새 북마크로 교체하세요. 서버 응답이 느릴 때는 동시 조회를 하더라도 오래 걸릴 수 있습니다.

이 설명서는 이미지가 포함된 HTML 한 파일입니다. 인터넷 연결 없이도 읽을 수 있습니다. 유플랫 수집에는 인터넷 연결과 유플랫 로그인이 필요합니다.
